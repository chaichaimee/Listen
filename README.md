## บทนำ

Listen Mode เป็นส่วนเสริมสำหรับ NVDA ที่ช่วยให้คุณสามารถเล่นและควบคุมไฟล์เสียงในโฟลเดอร์ปัจจุบันได้โดยตรงจาก File Explorer โดยไม่ต้องเปิดโปรแกรมเล่นเพลงแยกต่างหาก รองรับไฟล์เสียงหลากหลายรูปแบบและทำงานผ่าน MCI (Media Control Interface) ของ Windows

## คุณสมบัติหลัก

- เล่นไฟล์เสียงจาก File Explorer โดยตรง
- ควบคุมการเล่นด้วยคีย์ลัดใน Layer Mode
- ทำงานเบื้องหลังขณะใช้แอปพลิเคชันอื่น
- บันทึกตำแหน่งการเล่นอัตโนมัติ
- สร้าง Bookmark เพื่อจดจำตำแหน่งสำคัญ
- ปรับระดับเสียงได้
- ข้ามไปยังไฟล์ถัดไป/ก่อนหน้าในโฟลเดอร์เดียวกัน

## การติดตั้ง

1. ดาวน์โหลดไฟล์ `.nvda-addon`
2. เปิด NVDA → เครื่องมือ → จัดการส่วนเสริม
3. คลิก "ติดตั้ง" → เลือกไฟล์ `.nvda-addon`
4. รีสตาร์ท NVDA

## การใช้งานพื้นฐาน

### เริ่มต้นใช้งาน

1. เปิด File Explorer ไปยังโฟลเดอร์ที่มีไฟล์เสียง
2. ใช้ลูกศรเลือกไฟล์เสียงที่ต้องการ
3. กด `Alt+Windows+L` เพื่อเปิด Listen Mode
4. ระบบจะเล่นไฟล์เสียงทันที

### ออกจาก Listen Mode

- กด `Escape` หรือ `Q` เพื่อออกจาก Layer Mode
- การเล่นจะหยุดและบันทึกตำแหน่งปัจจุบัน

### การควบคุมใน Layer Mode

เมื่ออยู่ใน Layer Mode (ได้ยินเสียงบี๊พสูง 800Hz ตอนเปิดโหมด) คุณสามารถใช้คีย์ลัดต่อไปนี้:

| ปุ่ม | การทำงาน |
|------|----------|
| `Space` หรือ `C` | หยุดชั่วคราว / เล่นต่อ |
| `ลูกศรขวา` | ข้ามไปข้างหน้า 10 วินาที |
| `ลูกศรซ้าย` | ย้อนกลับ 10 วินาที |
| `Page Up` | เพิ่มระดับเสียง 2% |
| `Page Down` | ลดระดับเสียง 2% |
| `ลูกศรขึ้น` | เล่นไฟล์ถัดไปในโฟลเดอร์ |
| `ลูกศรลง` | เล่นไฟล์ก่อนหน้าในโฟลเดอร์ |
| `X` | เล่นไฟล์ปัจจุบันตั้งแต่ต้น |
| `Z` | ล้างประวัติตำแหน่งและ Bookmark ทั้งหมด |
| `W` | บอกเวลาที่เล่นไปแล้ว |
| `R` | บอกเวลาที่เหลือ |
| `T` | บอกความยาวทั้งหมดของไฟล์ |
| `E` | ข้ามไปยัง 10 วินาทีสุดท้าย |
| `B` | สร้าง Bookmark ณ ตำแหน่งปัจจุบัน |
| `Ctrl+B` | กระโดดไปยัง Bookmark ถัดไป |
| `Shift+B` | กระโดดย้อนกลับไปยัง Bookmark ก่อนหน้า |
| `Escape` หรือ `Q` | ออกจาก Layer Mode และหยุดเล่น |

## การทำงานนอก Layer Mode

Listen Mode ออกแบบมาให้ทำงานเบื้องหลังโดยไม่รบกวนการทำงานอื่น:

### สถานะขณะเล่น

- เมื่อเล่นไฟล์อยู่และคุณออกจาก Layer Mode (กด `Escape`) เพลงจะหยุดเล่นทันที
- หากต้องการให้เพลงเล่นต่อไปขณะทำงานอื่น: **อย่าออกจาก Layer Mode** เพียงแค่สลับไปยังหน้าต่างอื่นด้วย `Alt+Tab` หรือคลิกที่แอปอื่น

### พฤติกรรมเมื่อเปลี่ยนโฟกัส

1. **ขณะอยู่ใน Layer Mode**: คีย์ลัดทั้งหมดใน Listen Mode จะทำงานเฉพาะเมื่อคุณอยู่ในหน้าต่างเดิมที่เปิด Listen Mode
2. **เมื่อสลับไปแอปอื่น**: ปุ่มคีย์ลัดปกติของ NVDA และแอปพลิเคชันจะทำงานตามปกติ (พิมพ์, ลูกศร, Ctrl+C, ฯลฯ)
3. **กลับมาที่ File Explorer อีกครั้ง**: Listen Mode ยังคงทำงานอยู่ คุณสามารถใช้คีย์ลัดควบคุมได้ทันทีโดยไม่ต้องเปิดโหมดซ้ำ
4. **ต้องการปิด Listen Mode จริงๆ**: กด `Escape` หรือ `Q` เท่านั้น
