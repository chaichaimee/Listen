Listen


Contrôlez l'audio en arrière-plan depuis n'importe où. Se masque automatiquement lorsque vous changez de tâche et réapparaît à votre retour.


Auteur : chai chaimee

URL : https://github.com/chaichaimee/Listen


Introduction


Listen vous permet de lire un fichier audio directement depuis l'Explorateur de fichiers et de le contrôler avec de simples touches individuelles, sans ouvrir de lecteur multimédia. Sélectionnez un fichier audio, appuyez sur un raccourci clavier, et la lecture démarre pendant que vous continuez votre travail.


Lorsque le mode Listen est actif, les touches ordinaires telles que Espace, les flèches directionnelles, Page précédente et Page suivante deviennent des commandes de lecture. Lorsque vous basculez vers une autre fenêtre, les commandes se masquent automatiquement afin que votre clavier fonctionne à nouveau normalement. Lorsque vous revenez dans la fenêtre d'origine, les commandes réapparaissent et la lecture reprend si elle était arrêtée.


Listen mémorise votre position d'arrêt dans chaque fichier, votre niveau de volume ainsi que vos signets, afin que vous puissiez reprendre exactement là où vous en étiez.


Formats pris en charge : MP3, WAV, WMA, M4A, FLAC, AAC, OGG, OPUS, MID, MIDI


Raccourcis clavier


ALT+Windows+L
Appui simple : Ouvrir le mode Listen
Double appui : Fermer le mode Listen

Touches du mode couche


Ces touches fonctionnent uniquement lorsque le mode Listen est actif.


Lecture
Espace ou C : Lecture / Pause
Flèche droite : Avancer de 10 secondes
Flèche gauche : Reculer de 10 secondes
X : Redémarrer le fichier actuel depuis le début
E : Aller aux 10 dernières secondes du fichier
Flèche haut : Fichier audio précédent dans le dossier
Flèche bas : Fichier audio suivant dans le dossier
Échap ou Q : Masquer le mode Listen (la lecture continue)
Volume
Page précédente : Augmenter le volume
Page suivante : Diminuer le volume
Informations temporelles
W : Position actuelle
R : Temps restant
T : Durée totale
Signets
B : Ajouter un signet à la position actuelle
Ctrl+B : Aller au signet suivant
Maj+B : Aller au signet précédent
Déplacement en pourcentage
1 à 9 : Aller de 10 % à 90 % du fichier (1 = 10 %, 2 = 20 %, et ainsi de suite jusqu'à 9 = 90 %)
Historique
Z : Effacer toutes les positions enregistrées et tous les signets

Fonctionnalités


Démarrer l'écoute depuis l'Explorateur de fichiers


Listen agit sur le fichier audio actuellement focalisé dans une fenêtre de l'Explorateur de fichiers.


1. Dans l'Explorateur de fichiers, placez le focus sur un fichier audio pris en charge.
2. Appuyez une fois sur ALT+Windows+L.
3. Vous entendez un bip et NVDA annonce « Listen Mode Active ». La lecture démarre.
4. Si l'élément focalisé n'est pas un fichier audio pris en charge, NVDA annonce « Select Audio File ». Si le fichier ne peut pas être ouvert, NVDA annonce « Error loading file ».

Masquage et retour automatiques


Le mode Listen est lié à la fenêtre de l'Explorateur de fichiers dans laquelle vous l'avez démarré. Lorsque vous passez à une autre fenêtre, un bip grave retentit, NVDA annonce « Listen Mode Hidden » et les touches de couche sont libérées afin que chaque touche fonctionne normalement dans votre autre application. L'audio n'est pas interrompu.


Lorsque vous revenez dans la fenêtre d'origine, un bip retentit, NVDA annonce « Listen Mode Active » et les touches de couche sont de nouveau disponibles. Si la lecture avait été arrêtée, elle reprend.


Appuyer une fois sur ALT+Windows+L lorsque le mode Listen est masqué le réaffiche manuellement. Appuyer une fois alors que le mode Listen est déjà actif émet un court bip de confirmation.


Masquer sans arrêter


Appuyez sur Échap ou Q pour masquer le mode Listen tout en laissant la lecture continuer. C'est pratique lorsque vous souhaitez saisir du texte ou utiliser l'Explorateur normalement sans perdre votre musique. Appuyez une fois sur ALT+Windows+L pour faire réapparaître les commandes. Lorsque le mode Listen n'est pas utilisé, la touche Q se comporte comme d'habitude.


Fermer complètement le mode Listen


Appuyez deux fois sur ALT+Windows+L. La position de lecture, les signets et le volume sont enregistrés, le fichier est fermé et NVDA annonce « Permanently Stopped ». Le mode Listen ne reviendra pas tant que vous ne le redémarrerez pas depuis un fichier audio.


Reprendre là où vous vous êtes arrêté


Chaque fois qu'un fichier est arrêté, fermé ou que vous passez à un autre fichier, Listen enregistre sa position de lecture. La prochaine fois que vous ouvrirez ce même fichier, la lecture reprendra à la position enregistrée plutôt qu'au début.


Exemple : Vous écoutez une conférence jusqu'à 25:10 et fermez le mode Listen. Le lendemain, vous sélectionnez le même fichier et appuyez sur ALT+Windows+L. La conférence reprend à 25:10.


Parcourir les fichiers du dossier


Appuyez sur Flèche bas pour passer au fichier audio suivant ou sur Flèche haut pour le précédent. Listen examine le dossier du fichier actuel, classe les fichiers audio pris en charge par ordre alphabétique et lit le fichier voisin. NVDA annonce le nom du fichier. Après le dernier fichier, il revient au premier, et en reculant depuis le premier, il passe au dernier. Si le dossier ne contient aucun fichier audio, NVDA annonce « No audio files in folder ».


Signets


Vous pouvez marquer des moments importants dans un fichier et naviguer entre eux ultérieurement. Les signets sont enregistrés séparément pour chaque fichier.


1. Pendant la lecture du fichier, appuyez sur B au moment que vous souhaitez retenir.
2. Un bip aigu confirme le premier signet. Si le fichier possède déjà des signets, vous entendez deux bips consécutifs.
3. Répétez l'opération pour d'autres moments. Les signets sont conservés dans l'ordre chronologique.
4. Appuyez sur Ctrl+B pour aller au signet suivant, ou sur Maj+B pour aller au signet précédent. Un bip confirme chaque déplacement.
5. S'il n'y a pas de signet dans cette direction, un bip grave retentit.

Aucun signet n'est ajouté si un autre signet existe déjà à moins d'une demi-seconde de la position actuelle. Dans ce cas, vous entendez un seul bip court.


Déplacement en pourcentage


Les touches 1 à 9 déplacent la lecture à 10 %, 20 %, jusqu'à 90 % de la durée totale du fichier et NVDA annonce le pourcentage.


Exemple : Appuyez sur 5 pour aller au milieu du fichier. NVDA annonce « 50 percent ».


Annonces du temps


Appuyez sur W pour la position actuelle, R pour le temps restant et T pour la durée totale. Les durées sont vocalisées en minutes et secondes, ou en heures, minutes et secondes pour les fichiers plus longs.


Volume


Page précédente et Page suivante modifient le volume par petits pas entre 0 et 100. Le volume par défaut est de 40, et votre dernier niveau de volume est mémorisé lors de la prochaine utilisation de Listen.


Effacer l'historique


Appuyez sur Z pour supprimer toutes les positions de lecture enregistrées et tous les signets de tous les fichiers. NVDA annonce « History Cleared ».


Paramètres enregistrés


Votre volume, vos positions de lecture et vos signets sont enregistrés dans le fichier listen.json situé dans le dossier ChaiChaimee\Listen de votre dossier de configuration utilisateur NVDA. Si vous utilisiez une version antérieure, vos paramètres existants sont déplacés automatiquement vers ce nouvel emplacement lors du premier chargement de l'extension mise à jour.
