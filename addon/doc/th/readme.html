Listen


ควบคุมเสียงเบื้องหลังได้จากทุกที่ ซ่อนอัตโนมัติเมื่อคุณสลับงาน และกลับมาเมื่อคุณกลับเข้ามา


ผู้เขียน: chai chaimee

URL: https://github.com/chaichaimee/Listen


บทนำ


Listen ช่วยให้คุณเล่นไฟล์เสียงได้โดยตรงจาก File Explorer และควบคุมด้วยปุ่มเดี่ยวง่ายๆ โดยไม่ต้องเปิดโปรแกรมเล่นสื่อ เพียงเลือกไฟล์เสียงและกดปุ่มลัดหนึ่งครั้ง ไฟล์ก็จะเริ่มเล่นในขณะที่คุณทำงานอื่นต่อไป


ขณะที่อยู่ใน Listen Mode ปุ่มทั่วไปอย่าง Space ปุ่มลูกศร Page Up และ Page Down จะกลายเป็นปุ่มควบคุมการเล่น เมื่อคุณสลับไปหน้าต่างอื่น ปุ่มควบคุมจะซ่อนตัวอัตโนมัติเพื่อให้คีย์บอร์ดกลับมาทำงานตามปกติ เมื่อคุณกลับมาที่หน้าต่างเริ่มต้น ปุ่มควบคุมจะกลับมาและเสียงจะเล่นต่อหากถูกหยุดไว้


Listen จะจดจำตำแหน่งที่คุณหยุดไว้ในแต่ละไฟล์ ระดับเสียง และบุ๊กมาร์ก เพื่อให้คุณกลับมาฟังต่อได้ตรงจุดเดิมพอดี


รูปแบบไฟล์ที่รองรับ: MP3, WAV, WMA, M4A, FLAC, AAC, OGG, OPUS, MID, MIDI


ปุ่มลัด


ALT+Windows+L
กดครั้งเดียว : เปิด Listen Mode
กดสองครั้ง : ปิด Listen Mode

ปุ่มโหมดเลเยอร์


ปุ่มเหล่านี้จะใช้งานได้เฉพาะขณะที่ Listen Mode กำลังทำงานอยู่เท่านั้น


การเล่น
Space หรือ C : เล่น / หยุดชั่วคราว
ลูกศรขวา : กรอไปข้างหน้า 10 วินาที
ลูกศรซ้าย : กรอกลับ 10 วินาที
X : เริ่มเล่นไฟล์ปัจจุบันใหม่ตั้งแต่ต้น
E : กระโดดไปยัง 10 วินาทีสุดท้ายของไฟล์
ลูกศรขึ้น : ไฟล์เสียงก่อนหน้าในโฟลเดอร์
ลูกศรลง : ไฟล์เสียงถัดไปในโฟลเดอร์
Escape หรือ Q : ซ่อน Listen Mode (เสียงยังเล่นต่อไป)
ระดับเสียง
Page Up : เพิ่มระดับเสียง
Page Down : ลดระดับเสียง
ข้อมูลเวลา
W : ตำแหน่งปัจจุบัน
R : เวลาที่เหลืออยู่
T : ความยาวทั้งหมด
บุ๊กมาร์ก
B : เพิ่มบุ๊กมาร์กที่ตำแหน่งปัจจุบัน
Ctrl+B : ไปยังบุ๊กมาร์กถัดไป
Shift+B : ไปยังบุ๊กมาร์กก่อนหน้า
กระโดดตามเปอร์เซ็นต์
1 ถึง 9 : กระโดดไปยัง 10% ถึง 90% ของไฟล์ (1 = 10%, 2 = 20% ไปจนถึง 9 = 90%)
ประวัติ
Z : ล้างตำแหน่งที่บันทึกไว้และบุ๊กมาร์กทั้งหมด

ฟีเจอร์


เริ่มฟังจาก File Explorer


Listen จะทำงานกับไฟล์เสียงที่กำลังโฟกัสอยู่ในหน้าต่าง File Explorer


1. ใน File Explorer เลื่อนโฟกัสไปยังไฟล์เสียงที่รองรับ
2. กด ALT+Windows+L หนึ่งครั้ง
3. คุณจะได้ยินเสียงบี๊บและ NVDA จะพูดว่า „Listen Mode Active“ จากนั้นไฟล์จะเริ่มเล่น
4. หากรายการที่โฟกัสไม่ใช่ไฟล์เสียงที่รองรับ NVDA จะพูดว่า „Select Audio File“ หากเปิดไฟล์ไม่ได้ NVDA จะพูดว่า „Error loading file“

ซ่อนอัตโนมัติและกลับมาอัตโนมัติ


Listen Mode ผูกอยู่กับหน้าต่าง File Explorer ที่คุณเริ่มใช้งาน เมื่อคุณสลับไปหน้าต่างอื่น จะมีเสียงบี๊บต่ำดังขึ้น NVDA จะพูดว่า „Listen Mode Hidden“ และปุ่มเลเยอร์จะถูกปล่อยเพื่อให้ทุกปุ่มทำงานได้ตามปกติในแอปอื่น โดยที่เสียงจะไม่ถูกรบกวน


เมื่อคุณกลับมาที่หน้าต่างเดิม จะมีเสียงบี๊บดังขึ้น NVDA จะพูดว่า „Listen Mode Active“ และปุ่มเลเยอร์จะกลับมาใช้งานได้อีกครั้ง หากเสียงถูกหยุดไว้ก่อนหน้านี้ เสียงจะกลับมาเล่นต่อ


การกด ALT+Windows+L หนึ่งครั้งขณะที่ Listen Mode ถูกซ่อนอยู่ จะดึงโหมดกลับมาด้วยตนเอง การกดหนึ่งครั้งขณะที่ Listen Mode เปิดอยู่แล้ว จะมีเสียงบี๊บสั้นๆ เพื่อยืนยัน


ซ่อนโดยไม่หยุดเล่น


กด Escape หรือ Q เพื่อซ่อน Listen Mode ในขณะที่เสียงยังเล่นอยู่ ฟีเจอร์นี้มีประโยชน์เมื่อคุณต้องการพิมพ์หรือใช้ Explorer ตามปกติโดยไม่ให้เพลงหยุด กด ALT+Windows+L หนึ่งครั้งเพื่อนำปุ่มควบคุมกลับมา เมื่อไม่ได้ใช้งาน Listen Mode ปุ่ม Q จะทำงานตามปกติ


ปิด Listen Mode อย่างสมบูรณ์


กด ALT+Windows+L สองครั้ง ตำแหน่งการเล่น บุ๊กมาร์ก และระดับเสียงจะถูกบันทึก ไฟล์จะถูกปิด และ NVDA จะพูดว่า „Permanently Stopped“ Listen Mode จะไม่กลับมาจนกว่าคุณจะเริ่มใหม่อีกครั้งจากไฟล์เสียง


เล่นต่อจากจุดที่ค้างไว้


ทุกครั้งที่ไฟล์ถูกหยุด ถูกปิด หรือคุณย้ายไปไฟล์อื่น Listen จะบันทึกตำแหน่งการเล่นไว้ ครั้งถัดไปที่คุณเปิดไฟล์เดิม การเล่นจะดำเนินต่อจากตำแหน่งที่บันทึกไว้แทนที่จะเริ่มใหม่ตั้งแต่ต้น


ตัวอย่าง: คุณฟังเลกเชอร์ถึงนาทีที่ 25:10 แล้วปิด Listen Mode วันถัดมาคุณเลือกไฟล์เดิมแล้วกด ALT+Windows+L เลกเชอร์จะเล่นต่อจากนาทีที่ 25:10


เลือกดูไฟล์ในโฟลเดอร์


กด ลูกศรลง เพื่อไปไฟล์เสียงถัดไป หรือ ลูกศรขึ้น เพื่อไปไฟล์ก่อนหน้า Listen จะดูโฟลเดอร์ของไฟล์ปัจจุบัน เรียงลำดับไฟล์เสียงที่รองรับตามตัวอักษร แล้วเล่นไฟล์ที่อยู่ติดกัน NVDA จะประกาศชื่อไฟล์ หลังไฟล์สุดท้ายจะวนกลับไปไฟล์แรก และจากไฟล์แรกย้อนกลับจะวนไปไฟล์สุดท้าย หากในโฟลเดอร์ไม่มีไฟล์เสียง NVDA จะพูดว่า „No audio files in folder“


บุ๊กมาร์ก


คุณสามารถทำเครื่องหมายช่วงเวลาสำคัญในไฟล์และกระโดดกลับไปมาระหว่างจุดเหล่านั้นได้ในภายหลัง บุ๊กมาร์กจะถูกบันทึกแยกกันสำหรับแต่ละไฟล์


1. ขณะที่ไฟล์กำลังเล่น ให้กด B ณ จุดเวลาที่คุณต้องการจำ
2. เสียงบี๊บสูงจะยืนยันบุ๊กมาร์กแรก เมื่อไฟล์มีบุ๊กมาร์กอยู่แล้ว คุณจะได้ยินเสียงบี๊บสองครั้งติดกัน
3. ทำซ้ำสำหรับจุดอื่นๆ บุ๊กมาร์กจะถูกจัดเรียงตามลำดับเวลา
4. กด Ctrl+B เพื่อไปยังบุ๊กมาร์กถัดไป หรือ Shift+B เพื่อไปยังบุ๊กมาร์กก่อนหน้า จะมีเสียงบี๊บยืนยันทุกครั้งที่กระโดด
5. หากไม่มีบุ๊กมาร์กในทิศทางนั้น จะมีเสียงบี๊บต่ำดังขึ้น

ระบบจะไม่เพิ่มบุ๊กมาร์กหากมีบุ๊กมาร์กอื่นอยู่ห่างจากตำแหน่งปัจจุบันไม่เกินครึ่งวินาที ในกรณีนั้นคุณจะได้ยินเสียงบี๊บสั้นๆ เพียงครั้งเดียวแทน


กระโดดตามเปอร์เซ็นต์


ปุ่ม 1 ถึง 9 จะเลื่อนการเล่นไปยัง 10%, 20% ไปจนถึง 90% ของความยาวทั้งหมดของไฟล์ และ NVDA จะประกาศเปอร์เซ็นต์


ตัวอย่าง: กด 5 เพื่อกระโดดไปยังกึ่งกลางของไฟล์ NVDA จะพูดว่า „50 percent“


การประกาศเวลา


กด W เพื่อฟังตำแหน่งปัจจุบัน R เพื่อฟังเวลาที่เหลืออยู่ และ T เพื่อฟังความยาวทั้งหมด เวลาจะถูกอ่านเป็นนาทีและวินาที หรือเป็นชั่วโมง นาที และวินาทีสำหรับไฟล์ที่ยาวกว่า


ระดับเสียง


Page Up และ Page Down ใช้ปรับระดับเสียงทีละเล็กน้อยระหว่าง 0 ถึง 100 ค่าเริ่มต้นคือ 40 และระบบจะจดจำระดับเสียงล่าสุดของคุณไว้ใช้ในครั้งถัดไปที่ใช้ Listen


ล้างประวัติ


กด Z เพื่อลบตำแหน่งการเล่นและบุ๊กมาร์กที่บันทึกไว้ทั้งหมดของทุกไฟล์ NVDA จะพูดว่า „History Cleared“


การตั้งค่าที่บันทึกไว้


ระดับเสียง ตำแหน่งการเล่น และบุ๊กมาร์กของคุณจะถูกเก็บไว้ในไฟล์ listen.json ภายในโฟลเดอร์ ChaiChaimee\Listen ในโฟลเดอร์การตั้งค่าผู้ใช้ NVDA ของคุณ หากคุณเคยใช้เวอร์ชันก่อนหน้า การตั้งค่าเดิมจะถูกย้ายไปยังตำแหน่งใหม่นี้โดยอัตโนมัติในครั้งแรกที่โหลดส่วนเสริมเวอร์ชันอัปเดต



สนับสนุนผู้พัฒนา

หากเครื่องมือนี้ช่วยให้ชีวิตคุณง่ายขึ้น สามารถสนับสนุนการอัปเดตครั้งถัดไปด้วยเงินบริจาคเล็กๆ น้อยๆ ได้



การสนับสนุนของคุณมีความหมายมาก มาสร้างสรรค์สิ่งดีๆ ร่วมกันเถอะ
